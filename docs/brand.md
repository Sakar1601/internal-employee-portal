# Brand

## The mark

![Employee Portal logo mark](../app/frontend/public/logo.svg)

The mark is a small ledger: three horizontal rules, each beginning at a dot. It is the same picture the
**Roster timeline** draws in the app, where every employee is a bar that starts at a start date and runs to today.
The middle rule is drawn in the signal colour, the way a record is flagged after you change it.

- Source: [`app/frontend/public/logo.svg`](../app/frontend/public/logo.svg) (32 x 32 viewBox, rounded square, flat colour).
- In React: `LogoMark` and `Wordmark` in [`app/frontend/src/components/Logo.jsx`](../app/frontend/src/components/Logo.jsx).
- Minimum size: 16 px. Keep clear space of a quarter of the mark's width. Do not recolour except as listed below.

## Colour

| Token | Value | Use |
|---|---|---|
| `--ink` | `#16140f` | Text, the mark's tile, hard shadows |
| `--paper` | `#f2eee4` | Page background, rules on the mark |
| `--surface` | `#fbf9f3` | Panels and tables |
| `--accent` | `#1e5b4f` | Primary actions, tenure bars (verdigris) |
| `#6fc2ae` | | The flagged rule in the mark, on dark grounds |
| `--stamp` | `#a63a22` | Destructive actions, "just changed" marker |

A dark theme redefines the same tokens (`:root[data-theme="dark"]`). Department colours are not brand colours: each
department gets a stable hue from `shared/lib/departments.js`, rendered with theme-aware saturation and lightness.

The tokens live in [`app/frontend/src/styles/tokens.css`](../app/frontend/src/styles/tokens.css) and are shared by the app and
the project site.

## Type

- Display: Instrument Serif (headings, big numbers, the wordmark).
- Body: Hanken Grotesk.
- Data: IBM Plex Mono (record ids, dates, API log, labels).

All three are self-hosted through `@fontsource` packages; nothing is loaded from a third-party CDN.

## Where it is used

| Asset | File | Used for |
|---|---|---|
| Favicon | `app/frontend/public/logo.svg` | Browser tab, in the demo site and the real app |
| Touch icon | `app/frontend/public/apple-touch-icon.png` (180 x 180) | iOS home screen |
| Open Graph image | `app/frontend/public/og.png` (1200 x 630) | Link previews (`og:image`, `twitter:image`) |
| README banner | `docs/images/banner.png` (1600 x 420) | Top of the README |
| Header / nav / footer | `Logo.jsx` (`Wordmark`) | Site header and the portal's own header |

`og.png`, `apple-touch-icon.png` and `banner.png` are generated by
[`app/frontend/scripts/make-brand.mjs`](../app/frontend/scripts/make-brand.mjs) (`node scripts/make-brand.mjs`
from `app/frontend`), so they can be regenerated after any change to the mark or colours.
