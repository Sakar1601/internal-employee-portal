# Security Policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub: [Report a vulnerability](https://github.com/Sakar1601/internal-employee-portal/security/advisories/new)
(or **Security → Advisories → Report a vulnerability** on the repository page).
Include what you found, steps to reproduce, and the impact you expect.

You can expect an acknowledgement within 5 days and a status update within 14 days. Please give me reasonable time to
fix an issue before disclosing it publicly.

## Secrets

Never commit real credentials. Use `.env.example` (where present) as the template for local configuration.
